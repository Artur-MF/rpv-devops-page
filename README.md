# RPV DevOps Page

Landing page responsiva sobre DevOps, criada com HTML, CSS e JavaScript puros.

## Recursos

- Design moderno com tema escuro e detalhes em azul/ciano
- Layout responsivo para desktop, tablet e celular
- Menu mobile acessível
- Animações leves com suporte a `prefers-reduced-motion`
- Seções sobre benefícios, pipeline e ecossistema DevOps
- Sem dependências externas ou processo de build

## Executar localmente

Abra o arquivo `index.html` diretamente no navegador ou inicie um servidor local:

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.
